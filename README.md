## 一句话概括

用 Field II 3.30 复现 Montaldo 等（IEEE TUFFC, 2009）的单平面波成像与相干平面波复合（CPWC），以传统逐线聚焦 B 模式为对照，比较横向/轴向分辨率、囊肿对比度与 SNR，并对均匀随机散射子成像。**平面波角度固定为 11 个：$-10^\circ$ 到 $+10^\circ$，间隔 $2^\circ$。** 采集帧率只作为序列推导值列出，不列入实验对比；另设可选实验 E7，在 GPU 机器上实测“算法处理帧率”（本机无 GPU，未执行）。

## 核心结果（详见报告第 5 节）

| 方法 | 发射次数 | −10 dB 横向宽度 | 囊肿对比度 | 相对 SNR（30 mm） |
|---|---|---|---|---|
| 单平面波 | 1 | 1.00 mm | 25.2 dB | 0 dB |
| **11 角度复合** | **11** | **0.91–0.93 mm** | **45.2 dB** | **+8.8 dB** |
| 单焦点（30 mm） | 128 | 0.77 mm（45–55 mm 退化到 1.59 mm） | 30.4 dB | +10.8 dB |

趋势与论文 Table I 一致：复合在分辨率上接近单焦点、在对比度上超过单焦点、在 SNR 上接近最优多焦点。绝对数值差异来自二维体模、无衰减、无 TGC 与散射子密度，报告第 6 节逐项分析。

## 实现要点

- **Field II 延时陷阱**：`calc_scat_multi` 会把阵元发射激励延时写入该通道的时间轴，自定义 DAS 必须把 $x_1\sin\alpha/c$ 计入延时模型；否则倾斜平面波图像会横向剪切（$10^\circ$ 时约 5.2 mm），复合完全失效。定位方法与残差数据见报告 6.1 节。
- **相干复合必须在取包络之前、在 RF 域相加**。11 个角度合成的发射场在 30 mm 附近聚焦，焦点增益 10.2（理论 11），横向 −10 dB 宽度 1.76 mm，与物理聚焦的 1.62 mm 基本重合。
- **SNR 增益低于 $10\log_{10}n$**（8.8 dB 对 10.4 dB）：散斑在角度间只是部分相干，因此该公式对散斑目标只是上界；4 倍密度对照排除了“散射子密度不足”这一解释。

## 关于“帧率”：两个不同的量

| 名称 | 怎么得到 | 是否列入实验对比 |
|---|---|---|
| 采集帧率 $f_{PRF}/n$ | 由发射序列推导 | **否**（比较它等于比较发射次数 $n$） |
| 算法处理帧率 $1/t_{frame}$ | E7 在 CPU/GPU 上实测 | 可选，单独成表 |

采集帧率：$z_{max}=60$ mm 时 $f_{PRF}=12.83$ kHz，单平面波 12,833 Hz、11 角度复合 1167 Hz、单焦点 128 线 100 Hz。它只是方法背景，不作为实验指标。

算法处理帧率：`run/run_E7_gpu_throughput.m` 已实现（compute-only / end-to-end、CPU/GPU、NRMSE<1e-3 一致性校验），本机 `gpuDeviceCount=0` 故未执行。

## 复现

```matlab
cd ultrafast
addpath config src run
run_core            % E0–E5：11 角度 + 128 线 + 噪声 + 声场 + 分析（约 45 min）
run_tail            % 囊肿体模 + 重新分析（约 10 min）
make_figures        % 出图 F1–F13
make_fig_pointtargets   % 图 F14：点目标真实位置标注与定位误差
make_report_tables  % 出表 T-A…T-F
```

所有采集均可断点续跑：删除某个 `data/pw/*_a###.mat` 即可单独重跑该角度。

仓库包含代码、报告、结果表（`data/res/*.csv`）与图件（`figures/F1–F14.png`）；原始通道数据与 `results.mat` 未入库，运行上述脚本可重新生成。
