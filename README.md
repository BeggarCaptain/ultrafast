## 一句话概括

用 Field II 复现 Montaldo 等（IEEE TUFFC, 2009）的单平面波成像与相干平面波复合（CPWC），以传统逐线聚焦 B 模式为对照，比较横向分辨率、对比度与 SNR，并对均匀随机散射子成像。采集帧率只作为序列推导值列出，不列入实验对比；另设可选实验 E7，在 GPU 机器上实测“算法处理帧率”。

## 核心参数

| 项目 | 取值 |
|---|---|
| 阵列 | 128 阵元线阵，pitch 0.33 mm，4.5 MHz，60% 带宽 |
| 接收 F# | 1.75，无变迹 |
| 成像深度 | 5–60 mm |
| 复合角度 | 71 个，±16.5°（Eq. 6 网格） |
| 对照方法 | 单平面波、5/9/17/33/45/71 角度复合、单焦点逐线 |
| 体模 | 20k 均匀随机散射子；9 个 6 mm 无回声囊肿；8 个点目标 |

## 运行计划

- 核心仿真：约 3.5–4.5 h（199 次全量发射），正式运行前先通过 E0 参数标定。
- 可选 4 焦点参考组：约再增加 6 h。
- 可选 E7（GPU 算法处理帧率）：约 10–20 min，**默认不跑**，等明确要求且 GPU 机器可用时执行。

## 关于“帧率”：两个不同的量

| 名称 | 怎么得到 | 是否列入实验对比 |
|---|---|---|
| 采集帧率 $f_{PRF}/n$ | 由发射序列推导 | **否**（比较它等于比较发射次数 $n$） |
| 算法处理帧率 $1/t_{frame}$ | E7 在 CPU/GPU 上实测 | 可选，单独成表 |

采集帧率：$z_{max}=60$ mm 时 $f_{PRF}=12.83$ kHz，单平面波 12,833 Hz、C71 181 Hz、单焦点 128 线 100 Hz。它只是方法背景，不作为实验指标。

算法处理帧率：从通道 RF 到 B 模式的离线处理速度，取决于 CPU/GPU 与实现方式；E7 会区分 compute-only（数据已在显存）与 end-to-end（含约 170 MB/帧传输），并要求 GPU 结果与 CPU 一致（NRMSE < 1e-3）后才报告速度。

## 换机器继续

整个目录可整体拷贝到另一台机器；`run_core.m` 会跳过已存在的 `data/pw/angle_*.mat`，支持断点续跑。换机后先跑 `run_E0_calibration.m` 复核 MATLAB/Field II 版本；所有路径使用相对路径。E7 需要 CUDA GPU + Parallel Computing Toolbox，不满足时记录“未执行”，不影响主报告。
